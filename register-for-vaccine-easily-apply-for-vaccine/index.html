So today we will talk about how to register for vaccine easily by following the simple steps given below. Nowadays a number of coronavirus arises a lot in India. Get yourself vaccinated by the following easy method.

 

 

In India For Gujarat

**Registration for vaccine for the age above 18 will be start from   ** ->  28 April
**Vaccination for the age of above 18 will start from                           ** **->  1st May **

 

**How to register for a vaccine ? **

 

The registration for vaccines is done by two portals one of them is through the Aarogya Setu app and the second one is using the Co-win portal. here we are showing the Co-Win portal method for registration of vaccines. Following are the simple steps in order to register yourself for vaccine :

Step  1 ) Open up the website -> CO-WIN 

Step 2 ) Click on Register/ Sign in yourself.

Step 3 ) Enter your mobile number

Step 4 ) Verify the OTP

Step 5 ) Enter your basic details like name age gender and identity proof.

Step 6 ) Select the preferred vaccination centre and date.

Step 7 ) Visit the vaccination centre on the date you selected.

 

For senior citizen

 

Senior citizen can register for vaccine using the call centre number 1507.  if you can’t able to register yourself then please visit nearest vaccination centre.
